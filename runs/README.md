# Runs

This tree stores execution outputs and durable research artifacts created inside the project workspace.

Tracked files here should be intentional outputs, not transient harness runtime state.

Ephemeral session-start handoff artifacts live under `./session-briefs/` and are ignored by git except for the directory README.

Closed-cycle learning-loop artifacts live under `./learning-loops/` and are meant to capture carry-forward lessons, KB promotion candidates, and skill promotion candidates without mutating the external KB or core skill automatically.

Forum crawl artifacts live under `./forum-crawl/` and are meant to capture support-community evidence, template extraction, and KB/skill promotion triage.
