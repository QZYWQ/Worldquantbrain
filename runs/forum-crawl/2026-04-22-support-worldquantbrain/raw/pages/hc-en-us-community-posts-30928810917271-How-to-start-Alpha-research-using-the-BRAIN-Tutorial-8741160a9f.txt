This post is to explain how the BRAIN Tutorial that you can see on the right-side window of the Simulate page works, and how you can utilize it to learn about BRAIN and reach further level as an aspiring quant!

📌Introducing BRAIN Tutorial
: a step-by-step interactive guide to building your first Alphas in BRAIN:

All new users can access the Tutorial on the right-side window of the Simulate tab

Once you click “Start tutorial” button, the 30-day window begins for you to complete all the learnings and requirement in each of the 27 module.

If you complete the tutorial and meet all the requirements (including reaching Gold level) within the time window, a “Quantitative Finance Starter Level Certificate” will be issued to your email.

 

📌How each module works: 

You can check your tutorial learning progress and your progress till reaching Gold level(10,000 Challenge points) on the top of each tutorial module

Each module has a task that you need to try and succeed in order to proceed to the next learning module.

When you check the “RESULTS” tab, you can see whether you were able to successfully pass the task or not:

In case you are stuck with the task, there are ‘hints’ and ‘answers’ that can help you in the tutorial: 
 

Only if you succeed the task, the “Next” button on the bottom right will be activated, and you can move on the the following learning module. This continues till you finish the 27 modules.

You can utilize other learning resources on the platform (Learn page, videos, BRAIN Tips, live webinars, forum posts, etc.) that can help you pass the Tutorial tasks and help you earn your Quantitative Finance Starter Level certificate. 

If you have any questions about the Tutorial, or face any error while using it please feel free to send us a ticket, or leave comment below.

In short, the error occurs because the scl12_buzz data field has an incompatible unit (CSShare:1) for the ts_regression function, which expects a unit like Unit[]. 

Convert scl12_buzz to the correct unit using a function like unitconvert().

Ensure both scl12_buzz and volume are in compatible units for the ts_regression function.

Example fix:

ts_regression(unitconvert(-scl12_buzz, "CSShare:1", "Unit[]"), volume, 250)
