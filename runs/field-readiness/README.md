# Field Readiness

Store durable field-readiness gate outputs here when they should remain part of the project history.

These artifacts sit between `field-search-packs` and `expression-families` / local mining.

They are meant to answer a narrow question before local candidate generation:

- does this family have usable candidate fields on the current account
- do those usable fields have enough parseable coverage
- are baseline ideas still referencing blocked fields
