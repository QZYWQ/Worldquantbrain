# 2026-04-27 LITE SOP

## Scope

LITE is the execution clamp: make the future scout flow short, deterministic, and easy to close out.

The goal is a 15-minute path from a verified field name to a pass / fail decision with no orphan scout files.

## What Already Exists Locally

- `scripts/alpha_batch_miner.py` — local candidate generator
- `scripts/candidate_scorecard.py` — local structural scorecard
- `scripts/research_queue_builder.py` — queue prioritizer
- `scripts/alpha_family_factory.py` — family-level local bundle builder
- `scripts/worldquant_alpha_report.py` — live API simulation runner and markdown reporter
- `scripts/alpha_daily_runner.py` — local multi-family orchestrator

There is **no single existing script** that performs the whole flow of:

1. verify the field in Data Explorer
2. compute the S-1 distinctness / signal proxy
3. build the baseline and sign-flip S0 controls
4. record the result
5. clean up the temporary scout artifacts

That gap is why `scripts/lite-scout.sh` is needed as a scaffold.

## 15-Minute SOP

| Step | Action | Tooling | Expected time |
| --- | --- | --- | --- |
| 1 | Confirm the field exists in Data Explorer or in the saved inventory | manual browser check or inventory lookup | 2 min |
| 2 | Compute the S-1 proxy: `distinctness_score` and `signal_presence_score` | manual input or scaffolded helper | 3 min |
| 3 | If S-1 passes, build the S0 baseline `ts_rank(field, 60)` and the mandatory sign flip | `scripts/lite-scout.sh` scaffold or direct expression prep | 4 min |
| 4 | If live execution is allowed, submit the baseline and sign-flip pair; if not, write a dry-run record only | `scripts/worldquant_alpha_report.py` with explicit credentials, or dry-run mode | 4 min |
| 5 | Record the result, classify it, and delete temporary scout files | markdown note + cleanup | 2 min |

## Decision Rules

### S-1

- `distinctness_score >= 0.60`
- `signal_presence_score >= 0.40`
- If both are high risk, lower the priority or stop.
- If the field is not confirmed in Data Explorer, mark it `pending_verification` instead of `source_missing`.

### S0

- Baseline expression: `ts_rank(field, 60)`
- Settings: `USA`, `TOP3000`, `delay=1`, `decay=0`, default neutralization, `truncation=0.08`
- If the baseline Sharpe is negative, immediately run the sign-flipped control `-ts_rank(field, 60)`.
- Do not polish the original sign before the sign flip has been simulated and compared.
- If `TEST Sharpe >= 0.50` and Fitness is positive, the lane can be marked as a pass candidate.
- If the line still fails after sign flip, record the reason and stop.

### Cleanup

- Write the result into `runs/research-contracts/` as a prescreen result note.
- Delete any temp scout directory after the note is copied.
- Do not leave a scout file half-open for a future window.
