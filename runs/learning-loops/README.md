# Learning Loops

Store durable post-cycle learning-loop artifacts here.

Each closed cycle can write three deterministic files:

- `*-project-lessons.md`
- `*-kb-candidate.md`
- `*-skill-candidate.md`
- `*-promotion-gate.md`
- `*-kb-promotion-draft.md`
- `*-skill-promotion-draft.md`

These files are promotion candidates and structured carry-forward notes.
They are not permission to rewrite the external KB or the core skill blindly.
