# Harness Reports

This directory stores durable end-of-cycle markdown reports generated by:

- `./harness/coding-session.sh cycle-report`
- `./harness/coding-session.sh cycle-close`
- `./harness/coding-session.sh resume-brief`

Reports are not archives. They are closure artifacts that summarize cycle state before any later archive step.

`resume-brief` files are handoff artifacts for the next session, not state mutations.
