# 经验晋升与技能进化协议

## 用途

这份协议定义：

- 什么内容只该留在项目内
- 什么内容可以晋升为外部知识库候选
- 什么内容可以再进一步晋升为 WorldQuant skill 候选

目标不是“每轮自动改 skill”，而是让 AI 在长期 alpha 研究中稳定积累、稳定过滤、稳定进化。

## 总原则

晋升必须分层：

1. `project-lessons`
2. `kb-candidate`
3. `skill-candidate`
4. 外部知识库或 skill 的正式改动

不要跳层。

单轮 cycle 的闭环产物可以自动生成候选，但不能直接自动改写外部知识库或核心 skill。

## 触发时机

优先在完整闭环后触发：

- cycle 已形成真实研究产物
- 关键结论已有真实证据支撑
- 至少完成 `cycle-report`

推荐顺序：

1. `cycle-report`
2. `cycle-learning-loop`
3. 看 `promotion-gate`
4. 再决定是否真的升级到外部知识库或 skill

## 第一层：Project Lessons

保留在项目内即可的典型内容：

- 本轮的具体分支判断
- 本轮的 blocked 原因
- 当前账号、当前页面、当前字段的上下文
- 某个 family 在这轮里的真实结果

这些内容应该先进入：

- `runs/learning-loops/*-project-lessons.md`

不要因为它们“有用”就自动写进长期知识层。

## 第二层：KB Candidate

适合晋升到外部知识库候选的内容：

- 方法层经验
- 跨 cycle 可能重复适用的研究 heuristics
- 对字段搜索、分支优先级、低相关研究、证据纪律的稳定经验

必须同时满足：

- 不是官网当前事实
- 不是账号专属字段可用性
- 不是单字段、单 family、单 alpha verdict
- 有 durable 项目证据支撑
- 具备“以后还会反复用到”的合理性

默认反例：

- “`anl4_afv4_dts_spe` 不行”
- “某页面今天还是 `PENDING`”
- “这个 alpha 这次没过就说明这条路不值得做”

这些都不该直接进知识库。

## 第三层：Skill Candidate

只有更稳定、更抽象的流程规则才配进入 skill 候选。

适合进入 skill 候选的内容：

- 如何更快 kill 一个弱分支
- 什么时候必须阻止伪造 candidate-batch
- post-submit 后如何把 OS 监控与新研究 lane 分开
- 哪些失败模式必须在 workflow 中前置防守

必须同时满足：

- 是 workflow 规则，不是信号观点
- 能提升未来研究效率或证据严谨性
- 不削弱原有 hard rules
- 足够稳定，未来重复使用时大概率仍成立

默认更严格：

- 一轮结论通常只能生成 `skill-candidate`
- 真正修改 skill，优先等多轮重复证据后再做

## 自动化边界

允许自动化：

- 从 closed cycle 自动生成 `project-lessons`
- 自动生成 `kb-candidate`
- 自动生成 `skill-candidate`
- 自动生成 `promotion-gate`
- 自动生成 `kb-promotion-draft`
- 自动生成 `skill-promotion-draft`

不允许自动化：

- 自动写入外部知识库正文
- 自动修改 WorldQuant skill 的核心规则
- 自动把单轮失败推广成长期真理

## Promotion Gate 的作用

`promotion-gate` 负责把候选分成：

- `HOLD`
- `REVIEW`

含义：

- `HOLD`：暂时留在项目层，不升级
- `REVIEW`：可以进入人工审查，考虑升级到外部知识库或 skill

注意：

- `REVIEW` 也不等于自动正式晋升
- 真正晋升仍应作为单独改动完成

## 负面经验怎么写

负面经验最有价值，但最容易写坏。

正确写法：

- “如果 first sign test 很差，先 kill family，不要继续抛光”
- “如果缺真实 subuniverse/check evidence，就 block candidate-batch”

错误写法：

- “分析师分歧因子没用”
- “这个数据族都不值得研究”

前者是流程规则，后者是过度泛化。

## 与官网事实的边界

下面内容不该晋升为知识库或 skill：

- 当前提交阈值
- 当前 consultant / IQC 规则
- 当前 OS 页面状态
- 当前字段在账户上的可见性

这些必须回官方页面核实，不能当成长期稳定方法知识。
