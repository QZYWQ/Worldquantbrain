# 文档加载与真相源协议

## 何时读取

遇到下列情况时读取本文件：

- 不确定先读哪些文档
- 当前任务同时涉及项目状态、官网事实和外部知识库
- 不确定哪个文件才是当前真相源

默认不读本文件。只有在来源选择本身成为问题时才加载。

除链接以外，文中的路径约定默认按项目根目录解释。

## 最小读取原则

先读最小必需集合，不要全量扫目录。

默认起步：

1. [../AGENTS.md](../AGENTS.md)
2. [../00-项目总索引.md](../00-%E9%A1%B9%E7%9B%AE%E6%80%BB%E7%B4%A2%E5%BC%95.md)

按任务追加：

- 正式执行工作流：
  [../02-工作流索引.md](../02-%E5%B7%A5%E4%BD%9C%E6%B5%81%E7%B4%A2%E5%BC%95.md)
- 需要外部知识库定位：
  [../01-外部知识库映射.md](../01-%E5%A4%96%E9%83%A8%E7%9F%A5%E8%AF%86%E5%BA%93%E6%98%A0%E5%B0%84.md)
- 长任务、接力、cycle：
  [../harness/AGENTS.md](../harness/AGENTS.md)

不要做的事：

- 不要默认读取整个外部知识库
- 不要默认读取 `agent-policies/` 全部文件
- 不要把模板目录当作当前事实源

## 按任务选择真相源

### 当前项目执行状态

优先读当前项目目录中的真实产物和状态文件。

顺序：

1. `./runs/` 下的真实输出
2. `./harness/` 下的当前状态文件
3. 项目根目录索引与工作流文档
4. 外部知识库

### 当前平台官网事实或账号相关事实

优先读官方 WorldQuant BRAIN 页面。

顺序：

1. 官方页面或当前账号界面
2. 当前项目目录中的记录
3. 外部知识库中的公开资料总结
4. 帖子、评论、论坛经验

### 概念解释、公开经验、研究启发

优先读外部知识库映射后命中的具体笔记，再回到原始公开资料。

顺序：

1. `../01-外部知识库映射.md` 指向的目标笔记
2. 对应公开文档或帖子
3. 评论区技巧

这类内容只能当启发，不直接当当前平台事实。

## Harness 真相源细分

如果任务已进入 harness 模式，按这组真相源处理：

- 当前 cycle 选择：
  `../harness/active-cycle.txt`
- 任务结构与状态：
  当前 active cycle JSON
- 会话状态：
  `../harness/progress.md`
- 决策状态：
  `../harness/decision-log.md`
- 验证证据：
  `../harness/artifacts/`
- 周期报告与接力文档：
  `../harness/reports/`

## 硬规则

- 模板、脚手架、占位值不是结果。
- 外部知识库不是账号事实源。
- 评论区技巧不是官网规则。
- 若事实可能已变化，必须回官方页面核验。
- 若当前项目真实输出与旧笔记冲突，以当前真实输出为准。
