# 验证、证据与完成声明协议

## 何时读取

遇到下列情况时读取本文件：

- 准备说“已完成”“已修复”“已通过”
- 准备把结果写入 `runs/`、`harness/` 或对外摘要
- 准备把 alpha、指标、字段可用性或提交状态当成真实结论

默认不读本文件。只有当验证和声明边界会影响可信度时才加载。

除链接以外，文中的路径约定默认按项目根目录解释。

## 总规则

- 没有 fresh verification，不声明成功。
- 没有证据，不把结果写成已确认事实。
- 模板值、样例值、占位值不是结果。
- 公共帖子和评论区技巧只能当启发，不能当验证。

## 验证优先级

### 当前平台官网或账号事实

必须以官方 WorldQuant BRAIN 页面为准。

包括：

- 当前提交门槛
- 当前字段是否可见
- 当前账号能否访问某数据集
- 当前 simulation 或 submission 状态

### 当前项目输出

必须以本次会话刚生成或刚检查过的文件、命令输出和测试结果为准。

不要复用旧的“之前通过过”结论。

### 外部知识库和公开资料

只能支持理解、解释和研究启发，不能替代当前验证。

## 按产物类型验证

### 文档与索引改动

至少确认：

- 文件已创建或已更新
- 内容可读
- 路由和路径没有明显失效

### Harness 或脚本改动

至少运行对应的脚本检查、语法检查或测试。

### `runs/` 下的研究产物

至少确认：

- 文件真实存在
- 来源输入明确
- 不是模板直接改名

### Alpha 指标或提交结论

至少确认：

- 指标来自真实平台结果
- 必要时有截图、导出或记录可追溯
- 没有把样例值冒充真实值

## 允许的完成声明

只有在以下条件同时满足时，才能说任务已完成：

1. 目标文件或目标行为已经落地
2. 本轮相关验证已执行
3. 未验证部分被明确指出
4. 若涉及平台事实，已按官方边界核验

## 禁止事项

- 不要伪造 `Sharpe`、`Fitness`、`Turnover`、`Weight`、`Self-correlation` 等结果。
- 不要把模板样例当真实 capture、candidate 或 memo。
- 不要在修改后沿用旧验证结论。
- 不要把“看起来合理”写成“已经验证”。
